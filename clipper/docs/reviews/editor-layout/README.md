# Editing-page browser screenshots

These fourteen full-page screenshots are generated by
`python scripts/check_editor_browser.py` from the live `web/index.html`,
`web/style.css`, and `web/app.js`. The browser harness creates a disposable
review card with sample text and an empty video element, then switches the
real Content control between Music and Speech. They document layout, not a
completed media render: the rendered column shows its empty 9:16 frame.

The filenames identify mode and viewport: 390×844, 768×1024, 900×800,
1024×768, 1366×768, 1440×900, and 1920×1080. The script separately asserts computed pane geometry,
preview height and note placement, the rendered 9:16 frame's shape, fill,
placement and stacking (Issue #20), normal transcript word spacing, typography,
colors, overflow, keyboard focus, action-bar clearance, settings stability
between modes, and coarse-pointer target size. It fails on JavaScript or console
errors. It writes its screenshots and `results.json` to
`riceclipper-editor-browser/` in the system temp directory (or to
`RICECLIPPER_EDITOR_BROWSER_DIR`), never into the repository; copy the
screenshots here when the layout changes.
