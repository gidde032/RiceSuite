# RiceSuite logo — Issue #22

**Approved 2026-09-29 by the maintainer.** The Suite has its own symbol beside
the existing `RiceSuite` text. The Searcher, Clipper, and Poster marks remain
unchanged. Only the Suite shell uses this new mark.

The approved [board preview](final-board-preview.png) shows one Slate DJ
controller: a rice-stalk turntable, three fader caps shaped as individual rice
grains, and a master dial with a straight narrow rice stalk starting at its
center and two grains near its outer end. The [production PNG](../../../ricesuite/shell/logo.png)
is byte-identical to that approved preview and serves both the visible mark and
favicon. The [SVG](../../../ricesuite/shell/logo.svg) is an editable vector
reconstruction with simplified tonal detail for future scaling and edits.

The other images in this directory record the option and dial refinement rounds.
No pillar logo is a variant of the Suite logo.
