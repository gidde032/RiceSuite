# RiceSuite logo — Issue #22

**Approved 2026-09-29 by the maintainer; simplified in the follow-up.** The
Suite has its own symbol beside the existing `RiceSuite` text. The Searcher,
Clipper, and Poster marks remain unchanged. Only the Suite shell uses this mark.

The earlier [board preview](final-board-preview.png) established a Slate DJ
controller with a rice-stalk turntable, rice-grain faders, and a master dial.
The maintainer then selected **only its left disc with the curled rice-stalk
tonearm** as the final Suite mark. The [production PNG](../../../ricesuite/shell/logo.png)
was rerendered from that preview with the built-in imagegen edit tool on
2026-09-29. It has transparent surroundings and serves both the visible mark
and favicon. The [SVG](../../../ricesuite/shell/logo.svg) is an editable vector
reconstruction of the disc with simplified tonal detail; the PNG is the visual
authority.

Image edit instruction: isolate and center the left silver-ringed dark platter,
center spindle, and original curled rice-stalk tonearm with four grains; remove
the controller housing, sliders, and right dial; preserve the Slate monochrome
style and use a transparent background.

The other images in this directory record the option and dial refinement rounds.
No pillar logo is a variant of the Suite logo.
